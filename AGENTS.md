# Project AI instructions

Follow the project-specific code and selected rules. Read these documents before modifying relevant files:

- `docs/development-guidelines.md`
- `docs/git-workflow.md`
- `docs/documentation-index.md`
- `docs/AI-rules.md`

Keep detailed documentation in `docs/`. For every task classify visual-only vs logical. Visual-only changes do not require change logs. Document logical changes in `docs/change-log/`, and significant diagnosed errors in `docs/solving-mistakes/` if enabled. Do not modify unrelated files or silently commit/push.
